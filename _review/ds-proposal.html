Đề xuất hệ text style + màu semantic

Áp cho cả site (home, DEC, OneU). Dựng từ số đo computed style thật trên 3 trang ở viewport 1820, theo cấu trúc DS của chú, rút gọn: không có Global, theme chỉ có 2 mode Light/Dark. Chú duyệt xong tôi mới apply.

1. Cấu trúc

Tầng 1 · Theme (Light / Dark)Giá trị thô, có 2 mode. Không gắn thẳng vào component.
--theme-ink-100, --theme-surface-0, --theme-blue…
→
Tầng 2 · AliasChỉ 3 nhóm, gắn theo vai trò:
--object-* chữ, icon
--bg-* nền
--border-* viền
→
Component / HTMLChỉ dùng alias + class text style. Không màu thô, không khai font trong CSS của component.
  • Đổi mode = đổi tầng 1. html[data-theme=dark] chỉ ghi đè --theme-*. case-dark.css và phần dark trong theme.css (đang override từng component, khoảng 60 dòng) sẽ bị xoá.
  • Text style là class gắn thẳng vào HTML: <h1 class="t-h1-ux">. CSS component chỉ còn layout (margin, width…). Sửa cỡ H1 ở một chỗ là cả site đổi theo.
  • Tên style = vai trò cỡ + biến thể font. Mỗi vai trò có một bộ token size / line-height / letter-spacing dùng chung, còn font là biến thể đi kèm: t-h1-cal và t-h1-ux cùng ăn --h1-size. Chỗ nào cần Cal Sans to hay Uxum to thì chú chọn biến thể, không phải đẻ style mới.
  • Cách co giãn: giữ nguyên cách site đang chạy, cỡ ghi theo design 1920.
    • Body cố định px, ở đâu cũng vậy.
    • Display, Heading, Title, Note co theo --u. Home --u = 1px, case --u = min(100vw,1600px)/1920, mỗi style có cỡ sàn cho mobile.
  • Gradient (thanh AI, card, flap) là nhóm --paint-*, tương đương paint style, không thuộc 3 nhóm màu.
  • Figma: text style Heading/H1/Uxum, Body/B3/Medium… bind vào biến Typography/*. Biến màu: collection 1. Theme (mode Light · Dark) và 2. Alias. Tên biến CSS = tên lá, không tiền tố, đúng luật A3.

Ngoại lệ: màu minh hoạ, để nguyên trong component

Mấy màu này là một phần của hình minh hoạ, cố ý không đổi theo mode và không gom vào alias (tương đương Utility nhưng không tạo token):

  • Cursor chip "Claude-chan" #d97757 / #b65a3d và "You" #ea10ac / #cb0b96
  • Chữ nâu trên thumbnail Work rgba(92,61,48,.75 / .48), chữ trắng .8 trên ảnh
  • Nền đen pg-media, nền knob/thanh so sánh ảnh OneU (#007be5, #f2f2f4)
  • Màu trong ảnh/sprite

4. Chú chốt giúp tôi mấy điểm

  1. Các chỗ "đổi cỡ":
    • Throwbacks 64→56
    • OneU "Năng động" 60→56
    • Tagline và tab 22→20
    • Chữ 19u (15.8px) thành B2 16 cố định
    • Radio label 13.3→12
    Nhận hết hay giữ chỗ nào thì tôi tách thành style riêng.
  2. object-tertiary: gộp #b3b3b3 với .5 thành một mức .4. Hay tách 2 mức: tertiary .3 và .5?
  3. bg-layer-2: gộp cả nền CTA xanh nhạt #f6f8ff thành xám #f2f2f2. Hay chú muốn thêm bg-brand-subtle?
  4. Tên class: dùng t-h1-ux / t-b3-m như trên, hay gọn hơn h1-ux / b3-m?

5. Apply sau khi duyệt

  1. Viết css/base/tokens.css:
    • Theme light/dark và alias màu
    • Token typography và class t-*
    File này thay phần biến trong type.css, thumb.css, about.css, spotlight.css, case.css, theme.css, case-dark.css.
  2. Script gắn class text style vào HTML theo bảng map, rồi gỡ khai font khỏi CSS component.
  3. Thay mọi màu thô trong CSS bằng alias. Xoá các override dark theo component.
  4. Chụp trước/sau từng trang, cả light và dark, để soi chỗ lệch ngoài các mục "đổi cỡ" đã duyệt.
